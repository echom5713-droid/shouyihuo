## 发现并修复的问题

1. 首轮运行在 1280×800 下发现右侧“运行复测”被页脚覆盖，真实点击被阻止。修复 Canvas 所在 flex/grid 的高度约束、Canvas 定位与工具栏布局后，完整路径重新通过。原错误上下文和截图保存在 `regression-found/retest-footer-overlap.md` 与同名 PNG；没有使用强制点击绕过遮挡。
2. 复查 100 分但有安全错误的报告，发现复习建议曾把修复后已恢复供水的终态描述为“仍需”处理。已改为下次拆卸前的通用安全提醒，并增加单元断言；最终截图已检查修正文案。
3. Three.js 当前版本自动将已移除的 `PCFSoftShadowMap` 转为 `PCFShadowMap`。代码改为实际使用的后者，消除本轮新增的控制台提示；保留原依赖版本。
4. 独立检查还促成桌面工具栏单行排列、滚动提示及按真实完成条件显示阶段图标，避免诊断错误被画为已完成。
