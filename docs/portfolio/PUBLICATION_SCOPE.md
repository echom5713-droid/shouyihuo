# Publication scope

This is a bilingual portfolio edition of Shouyihuo Local MVP v0.2, prepared on 5 October 2026. The application and review page start in English and offer an English / 中文 switch. The repository overview, technical case study, review guide and project brief are primarily in English; Chinese setup instructions are retained.

## Intended public contents

- Complete application source and dependency lockfile.
- Business-rule tests, browser tests and a synthetic compatibility fixture.
- English and Chinese setup instructions.
- Technical documentation, actual test evidence and selected runtime screenshots.
- An English project brief with an explicit AI-assistance and limitations statement.

The repository is a technical project record, not a university-endorsed project or an admission credential. Programme-specific application notes are distributed separately and are not included in the public repository.

## Excluded from the publication package

- Browser profiles, personal learning records and credentials.
- Dependency folders, browser binaries, generated Playwright traces and unreviewed session files.
- Personal statements, university application plans and private academic records.
- The original conversational product brief; the public documentation explains the actual implementation.

No licence grant is inferred from publication. No software licence has been selected in this edition; third-party packages retain their own licences. Public source visibility alone is not an open-source licence.

## History and authorship

The original development workspace did not have a Git history. The public repository therefore starts with an honest import of the existing project, rather than fabricated earlier implementation commits or backdated authorship. The original source import was published before the later bilingual update. Subsequent commits record actual package changes; they do not reconstruct an unaided development history. See [Provenance](PROVENANCE.md).

## Hosting and local data

A GitHub source repository is not automatically a hosted application. Follow the README to run the application locally. If a hosted demo is added later, it will have a different browser origin and will not contain the user's existing localhost learning records. Do not upload localStorage exports as demonstration data.
