## 发现、修复与最终状态

1. **测试启动问题，已修复**：Node ESM 对 JSON fixture 的直接 import 需要属性，改为读取冻结 fixture 文件；不涉及应用逻辑。
2. **真实布局回归，已修复**：视口变化后 Canvas 百分比高度撑大网格，页脚拦截复测按钮。调整网格行和 Canvas 容器约束，复测按钮真实点击与全套 E2E 重跑通过；未用 force 点击。失败上下文和截图保留在 `validation-v0.2/regression-found/`。
3. **画面与交互修正**：桌面工具栏合一行增加模型高度；俯视时盖呈现到后上方；聚焦按边界角点取景；拖动超过阈值不触发选择；标签增加引线；手机去除不适用的内层滚动提示。
4. **报告文案修正**：将正常修复终态与再次拆卸前条件区分，安全建议引用真实错误并提醒下次流程。
5. **依赖兼容提示处理**：试用的 PCFSoftShadowMap 在当前 Three 版本中会自动回退，已直接使用实际支持的 PCFShadowMap，新增提示消失。最终仍有原依赖的 `THREE.Clock` 弃用提示及 Three 分包约 944 kB 的构建提示；均未导致测试失败。

最终类型检查、40 单测、12 E2E、构建和生产预览均通过，没有保留已知阻断问题。没有为了通过测试删掉原业务断言或放宽评分/安全规则。
