# 手艺活 Local MVP v0.2 · UI / UX 与 3D 精修

本轮是在 v0.1 工程上迭代，未迁移框架、未升级依赖、未新增课程或服务。开发与验收日期：2026-09-26。教学原型，内容未经维修专业人士审核，仅适用于内置简化模型。

## 修改前基线

已读取工程源码、README、业务测试、E2E、历史验收记录与截图；当前目录没有 Git 仓库，也没有 AGENTS.md。任务指定的升级文档最初不在本地根目录，已读取同名原始文件并保存在项目根目录 `shouyihuo_codex_v0.2_ui_upgrade.md`。

修改前实际执行类型检查、25 项业务单测、7 项 E2E、生产构建，全部通过。旧截图与本轮重新运行生成的基线截图分别保存在 `baseline-v0.1/screenshots/` 和 `baseline-v0.1/runtime-screenshots/`；日志在同目录。历史报告仅作参考，没有充当本轮测试结果。

旧界面主要问题：字体和辅助文字对比度偏低；训练入口靠下；观察阶段突出复测按钮；默认选中进水组件时，拆装下拉框却选择排水组件；报告通过与失败的背景区分不足；查看内部、聚焦部件与扩大模型空间不方便。

## 实际改动

### 统一阅读与操作层级

- CSS 按设计变量、导航、首页、工作台、报告、记录、弹窗、响应式和打印分类整理。使用系统字体，正文以 15 px 为基准，部件说明及主要操作 14 px，安全条件 14 px，辅助说明最低 12 px。
- 浅灰白页面、白面板和深绿色强调色；警告与错误同时显示文字，不只靠颜色。按钮提供 hover、active、focus-visible、selected、disabled 状态。
- 首页三种模式入口和症状选择进入桌面首屏；实际未结束的学习显示继续入口，新尝试保留确认。首页模型是独立观察实例，不写入训练会话。
- 报告先展示最终判定与原因，再给出最多三条来自本地规则的复习建议和评分明细。100 分且有关键安全错误时显示琥珀色未合格结果，不显示合格证明。
- 学习记录、昵称、筛选、继续学习与清空确认保留。手机记录列表改为纵向排列；证明打印与限制说明保持可读。

### 工作台

- 顶部“观察—诊断—处理—复测”只读反映引擎状态，不是跳关导航。观察证据达到提交门槛、首次诊断是否正确、有效处理与完整复测分别决定阶段展示；错误诊断用错误图标明确标记。
- 观察阶段突出记录观察，诊断阶段突出提交，处理阶段突出适用的当前处理动作，准备完成后才突出复测。结束报告和重开尝试保留为次要动作。
- 单一 `selected` 决定模型、部件目录、说明与操作目标；不提供拆装的部件会显示原因，选中其他部件时不暗中保留另一组件为操作目标。
- 桌面左右面板独立、可控滚动，操作面板有滚动说明；日志默认折叠，展开叠在场景下方，不压缩 Canvas。
- 安全条件常驻。非法拆卸仍提交给原 reducer，由引擎拒绝并记录错误；错误摘要持续显示，可展开追溯。复测中才禁用会改变供水或装配的操作。
- 复测文案直接使用 filling、holding、draining、refilling、passed、failed 对应真实状态；通过工作循环不被描述成整场测评合格。

### 真实三维呈现

- 继续使用程序化空腔水箱；调整陶瓷、塑料、金属、橡胶和水体材质，中性光照、较轻阴影、较清透水体与克制选中高亮。
- 增加整体视角、俯视内部、主动聚焦选中部件。普通选择不会强制移动镜头；俯视不会自动开盖；开盖时箱盖向上后方呈现，保留同一个业务状态。
- 根据画布长宽比与爆炸状态调整取景；标签按世界坐标动态投影，用细线关联部件，处理出画、背面、遮挡和重叠，优先排布选中项。
- 放大工作区通过原节点布局实现，保留同一个 Canvas、attempt 和模拟时钟；可点击退出或按 Esc，焦点返回原按钮，不需要系统全屏权限。
- 尊重 `prefers-reduced-motion`：镜头、爆炸、浮球、水体插值和水流动画均响应；必要业务水位仍更新。触摸单指滚页、双指操作模型。
- WebGL 不可用或上下文丢失时保留二维规则交互，并明确禁用需要 WebGL 的镜头工具。

## 业务与数据兼容

课程、案例、事件、模拟、评分、安全规则、持久化实现和原业务单测与 v0.1 源码逐字一致。比对结果见 `validation-v0.2/business-preservation.json`。锁文件除本项目版本从 0.1.0 改为 0.2.0 外，依赖条目未变。

继续使用 `shouyihuo.local.v1` 和 `schemaVersion: 1`，不迁移、不清空。旧格式 fixture 在修改前由 v0.1 reducer 生成，用于兼容验证；正常通关 E2E 通过真实页面操作，不注入完成状态。

切换页面、镜头、剖视、爆炸、侧栏和放大只改变展示。首页开始新尝试与继续学习明确分开，原有确认和已完成记录不可变规则保留。首次诊断规则、25/30/25/20 评分权重、80 分门槛及无关键安全错误要求不变。

升级时停止旧服务，再在新版目录启动，并继续使用同一浏览器的同一地址 `http://127.0.0.1:5173/`。目录变化不影响 origin；改成 localhost、换端口或换浏览器会读取不同存储位置，不能误认为版本升级清空了记录。

## 实际回归与画面修正

第一轮浏览器完整路径发现视口切换后 Canvas 的百分比高度影响网格的内容尺寸，导致页脚覆盖复测按钮。已改为确定的网格行、绝对定位场景容器和可收缩的面板；没有用强制点击规避。原始失败截图与上下文保存在 `validation-v0.2/regression-found/`。

打开新版 1366×768 工作台后，把桌面模型工具栏合并为一行，增加可用 Canvas 高度；补充右侧滚动提示；修正错诊断与“已完成”图标的歧义。模型专项检查还修正了爆炸裁切、俯视时箱盖遮挡与阴影强度。

最终命令、通过数、真实截图索引和未验证范围见 [TEST_REPORT.md](TEST_REPORT.md)。所有 `screenshots/v0.2/` 图像均来自本轮实际 Chromium 运行，未使用旧截图或静态设计稿替代。

## 已知边界

只验证本教学模型与本轮自动化覆盖路径；没有专业维修审核和现场设备对照。Linux Chromium WebGL 2 / SwiftShader 的结果不等同于用户 Windows 原生显卡或所有浏览器的表现。移动端做可用性降级，精细模型操作仍优先桌面鼠标。实际打印机、Windows PDF 保存对话框和实体触摸设备需在对应设备上进一步检查。
